## Conventions

- Layout is `domain/topic/`. A small topic is a single `.md` file; a larger one is a folder whose entry point is `README.md`.
- File and folder names use lowercase-kebab-case.
- Images go in an `assets/` folder next to the note that uses them.
- New notes start from [`_templates/topic.md`](_templates/topic.md).
- Add each new note to the Contents table above.
